## ✨ What it does
- Starts with a funny "verify who you are" screen
- A cute "feelings loading" animation
- Ends with a personal letter
- Works on phones, no install, no sign-up

## 🔗 Personalise with a link
Add the names to the end of the address:

```
?name=Riya&from=Priyanshu
```

Want your own message in the final letter? Add `&msg=` with your text (URL-encoded):

```
?name=Riya&from=Priyanshu&msg=Your%20message%20here
```

Or open the **link maker** (`?make=1`) and it builds the link for you.

## 📁 Files
| File | What it is |
|---|---|
| `index.html` | the page |
| `styles.css` | design and animations |
| `script.js` | text (see `CONFIG` at the top) and logic |

## 🛠️ Edit the text
Open `script.js`. All the words live in the `CONFIG` block at the top. Change them and you have your own version.
